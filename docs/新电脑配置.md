# 新电脑配置（clone 之后）

换电脑后，Git 只会带上代码和 `config.yaml`。登录态、密钥、运行记录都不会过来，必须在本机再配一遍。

## 不会随仓库过来的内容

| 路径 | 原因 |
|------|------|
| `.env` | API Key、博客园账密、邮箱授权码 |
| `auth/` | 知乎 / 三丰云 / 阿贝云 / 博客园的 Cookie 和 Chrome 配置 |
| `data/` | 上次延期是否已跑过 |
| `logs/`、`output/` | 日志和生成结果 |

旧电脑上的 `auth/` **不要拷贝**，换机后浏览器指纹不同，容易登录失败。`.env` 可以U盘拷贝，也可以按下面新建。

---

## 1. 环境

- Windows 10/11
- Python 3.10 或更高（`python --version`）
- 已安装 Google Chrome（没有则装 Edge，脚本会回退）
- Git

## 2. 拉代码并装依赖

在仓库根目录执行：

```bat
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python -m playwright install chromium
```

日常用本机 Chrome，`playwright install chromium` 仍建议跑一次，避免驱动缺失。

## 3. 填写 `.env`

```bat
copy .env.example .env
```

用记事本打开 `.env`，填这些变量（等号后面不要加引号）：

| 变量 | 填什么 |
|------|--------|
| `DEEPSEEK_API_KEY` | DeepSeek 控制台的 API Key |
| `CNBLOGS_USERNAME` | 博客园登录名 |
| `CNBLOGS_PASSWORD` | 博客园密码 |
| `SMTP_USERNAME` | 发信邮箱，如 `you@163.com` |
| `SMTP_PASSWORD` | 163 **授权码**（不是登录密码） |
| `NOTIFY_EMAIL_TO` | 接收审核提醒的邮箱，多个用英文逗号分隔 |

旧仓库的 `docs/AI/base.md` 里曾经写过明文 Key，**请到 DeepSeek 作废旧 Key 并换新的**，再把新 Key 只写进 `.env`。

## 4. 确认 `config.yaml`

一般不用改。换机后只需核对：

1. **Chrome 路径** `browser.executable_path`  
   默认是 `C:\Program Files\Google\Chrome\Application\chrome.exe`。  
   如果本机不在这个位置，改成实际路径；也可以不管，脚本会自动找 Chrome / Edge。
2. **云服务器地址**（同一台机器则不用改）  
   - 三丰云：`sanfeng.server_url`  
   - 阿贝云：`abeiyun.server_url`  
   换了免费机实例，把 URL 末尾的数字改成新的服务器 ID。
3. 邮箱通知：`notification.email.enabled` 为 `true` 时才会发审核提醒邮件。

## 5. 重新登录（必做）

每个站点在本机登录一次，Cookie 会存到 `auth/`（已在 `.gitignore` 里）。

在仓库根目录、已 `activate` 虚拟环境后：

```bat
python scripts\init_zhihu_auth.py
python scripts\init_sanfeng_auth.py
python scripts\init_abeiyun_auth.py
python scripts\init_cnblogs_auth.py
```

| 脚本 | 你要做的事 |
|------|------------|
| 知乎 | 浏览器打开后扫码/登录，确认能进专栏写作页，回到终端按 Enter |
| 三丰云 | 确认账号密码已填，点登录，回到终端按 Enter |
| 阿贝云 | 同上 |
| 博客园 | 脚本会按 `.env` 填账密；如有验证码就手动过，登录成功后按 Enter |

登录失败时不要继续跑主程序，先把对应 init 脚本跑通。

## 6. 先试跑

```bat
python main.py --keepalive-only
```

能打开知乎并刷新登录态，说明浏览器和知乎 Cookie 正常。

只检查到期、不发帖、不提交：

```bat
python main.py
```

到期时间还剩超过 26 小时会跳过发帖，这是正常的。还剩 26 小时以内（且未过期）才会跑续期。日志在 `logs/年-月/run_年-月-日.log`，例如 `logs/2026-09/run_2026-09-17.log`。

知乎登录态失效时，脚本会打开登录页、把二维码截图发到邮箱，并保持浏览器等待扫码（最长 12 小时，每 10 分钟换新码再发一封）。扫码后不用回信。

强制整条流水线（生成文章 → 知乎 → 博客园 → 云厂商填表）：

```bat
python main.py --force
```

只跑一家：

```bat
python main.py --force --provider sanfeng
python main.py --force --provider abeiyun
```

## 7. 定时任务（可选）

新电脑上 **以管理员身份** 运行一次：

```bat
scripts\install_scheduled_task.bat
```

会注册 Windows 任务 `SanfengCloudAutoRenew`，每 2 小时执行 `python main.py --scheduled`。

任务用的是系统 PATH 里的 `python`。若你只用 `.venv`，先保证「系统能直接运行 python」，或改任务的起始程序为：

```text
<仓库>\.venv\Scripts\python.exe
```

参数仍为：`main.py --scheduled`，起始于仓库根目录。

## 8. 换机后常见问题

| 现象 | 处理 |
|------|------|
| `env DEEPSEEK_API_KEY is empty` | `.env` 没放在仓库根目录，或变量名写错 |
| `Chrome path not found` / 打不开浏览器 | 安装 Chrome，或改 `config.yaml` 的 `executable_path` |
| 停在登录页 / credentials empty | 云厂商：重新跑对应的 `scripts\init_*_auth.py`。知乎：看邮箱里的二维码邮件，扫服务器上开着的 Chrome；或远程桌面直接扫当前页 |
| `Expiry datetime not found after label` | 页面数据慢或未登录；脚本会等最多 30 秒，仍失败就看 `logs/年-月/expiry_not_found.png` |
| 定时任务跑了但没日志 | 任务里的 python 不是你装依赖的那个；改成 `.venv\Scripts\python.exe` |
| `mkdtemp ...\Temp\2\playwright-artifacts` | 远程桌面会话的临时目录不存在；脚本会自动创建。也可手动建 `C:\Users\Administrator\AppData\Local\Temp\2` |

## 9. 推远程前不要带上去的

确认这些没有被 `git add`：

- `.env`
- `auth/`
- `data/`
- `logs/`
- `output/`

`git status` 里不应出现它们。密钥只允许出现在 `.env`，不要写进 `docs/` 或 `config.yaml`。
