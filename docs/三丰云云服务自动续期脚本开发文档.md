# 三丰云云服务自动续期脚本 — 开发文档

> 文档版本：v1.1  
> 更新日期：2026-08-26  
> 状态：一期开发中（知乎 + AI）；三丰云续期提交为二期

---

## 1. 项目概述

### 1.1 背景

用户需要在知乎专栏定期发布文章，并将发布结果（截图 + 文章 URL）提交至三丰云服务器后台，用于云服务续期或相关审核流程。当前流程为人工操作，耗时长且易遗漏。

### 1.2 目标

开发一套 **低频、可长期运行** 的浏览器自动化脚本，实现：

1. 调用 AI 生成不重复的标题与正文；
2. 自动在知乎专栏发布文章，并选择固定话题；
3. 发布后自动截图，获取文章 URL；
4. ~~跳转三丰云后台，上传截图、填写 URL 并提交表单~~（**二期**）；
5. 每 **5 天** 执行一次，并保留完整运行日志与备份。

### 1.3 非目标（本期不做）

- 高并发、批量发帖；
- 完全无人值守的验证码破解；
- 多账号轮换；
- 复杂的 Web 管理后台；
- **三丰云续期页自动提交**（二期，待续期页 DOM 确认后再做）。

### 1.4 分期规划

| 阶段 | 范围 | 状态 |
|------|------|------|
| **一期** | AI 生成 → 知乎发帖（话题「三丰云服务器」）→ 全页截图 + URL → 调度与日志 | 开发中 |
| **二期** | 三丰云账密登录 → 续期页上传截图 + 填 URL + 提交 | 待续期页 HTML/选择器 |

### 1.5 已确认参数（见 `docs/全局要求.md`）

| 项 | 值 |
|----|-----|
| 知乎固定话题 | `三丰云服务器` |
| 正文字数 | **100–300 字**（以此为准，非 800–2500） |
| 正文必含关键词 | `三丰云服务器`、`免费云服务器` |
| AI 供应商 | DeepSeek（`deepseek-v4-flash`） |
| 三丰云登录 | 仅账密，忽略扫码入口 |
| 截图 | 全页 |
| 运行环境 | 本机 Windows，几乎每天开机 |
| 通知 | 仅本地日志，后续可扩展 |

## 2. 需求说明

### 2.1 功能需求

| 编号 | 模块 | 描述 |
|------|------|------|
| FR-01 | AI 内容生成 | 根据配置的提示词模板生成标题、正文，避免每次内容相同 |
| FR-02 | 知乎发帖 | 打开 `https://zhuanlan.zhihu.com/write`，填入标题与正文 |
| FR-03 | 话题选择 | 自动选择 **固定** 的预设话题（可配置多个） |
| FR-04 | 发布确认 | 点击发布，等待跳转至文章页（URL 含 `/p/`） |
| FR-05 | 截图与 URL | 对发布成功页截图，记录浏览器当前 URL |
| FR-06 | 三丰云登录 | **（二期）** 打开后台；浏览器已记住账密，脚本点击「登录」 |
| FR-07 | 表单提交 | **（二期）** 上传截图、在 URL 输入框填入知乎文章链接、提交表单 |
| FR-08 | 定时调度 | 每 5 天执行一次（或距上次成功 ≥ 5 天） |
| FR-09 | 日志与备份 | 保存每次运行的截图、URL、AI 原文、成功/失败状态 |

### 2.2 非功能需求

| 编号 | 描述 |
|------|------|
| NFR-01 | 单次全流程失败时，应输出明确错误信息，便于人工介入 |
| NFR-02 | 登录态过期时，脚本应停止并提示重新登录，不应静默失败 |
| NFR-03 | 选择器、URL、话题等配置与代码分离，便于维护 |
| NFR-04 | 开发阶段使用有界面浏览器（`headless=False`），便于调试 |

### 2.3 业务约束

- **发帖频率**：5 天 1 条，降低平台风控风险；
- **内容来源**：AI 生成，正文 **100–300 字**，必须含「三丰云服务器」「免费云服务器」；
- **知乎话题**：固定为「三丰云服务器」；
- **三丰云登录**（二期）：账密登录，不用扫码；浏览器已保存凭据，点击登录即可；
- **提交内容**（二期）：截图文件与知乎文章 URL 均需上传/填写。

## 3. 技术方案

### 3.1 技术选型

| 组件 | 选型 | 理由 |
|------|------|------|
| 语言 | Python 3.10+ | 生态成熟，上手快 |
| 浏览器自动化 | Playwright | 截图、文件上传、登录态持久化（`storageState`）支持好 |
| AI 接口 | OpenAI 兼容 API | 可对接 OpenAI / DeepSeek / 通义等，统一调用方式 |
| 配置 | YAML | 话题、URL、提示词、调度间隔等外置 |
| 调度 | Windows 任务计划程序 | 用户环境为 Windows；亦可在脚本内做间隔判断 |

### 3.2 系统架构

```
┌─────────────────────────────────────────────────────────────┐
│                        main.py（主流程）                      │
└─────────────────────────────────────────────────────────────┘
        │              │              │              │
        ▼              ▼              ▼              ▼
┌──────────────┐ ┌──────────────┐ ┌──────────────┐ ┌──────────────┐
│ generate_    │ │ post_zhihu   │ │ submit_      │ │ scheduler /  │
│ content.py   │ │ .py          │ │ sanfeng.py   │ │ logger       │
│ （AI 生成）   │ │ （知乎发帖）  │ │ （三丰云提交）│ │ （调度日志）  │
└──────────────┘ └──────────────┘ └──────────────┘ └──────────────┘
        │              │              │
        ▼              ▼              ▼
   AI API         Playwright       Playwright
                  + zhihu_state    + sanfeng_state
```

### 3.3 数据流

```
[读取 config.yaml]
        ↓
[AI 生成 title + body]
        ↓
[Playwright 打开知乎 /write]
        ↓
[填标题 → 填正文 → 选固定话题 → 发布]
        ↓
[等待 URL 变为 /p/xxxx]
        ↓
[截图保存 + 记录 URL]
        ↓
[Playwright 打开三丰云后台]
        ↓
[点击登录（如未登录）→ 进入目标表单页]
        ↓
[上传截图 → 填写 URL → 提交]
        ↓
[写入 output/ 与 logs/ → 更新 last_run 记录]
```

## 5. 配置说明

### 5.1 config.yaml 示例

```yaml
# 调度
schedule:
  interval_days: 5              # 距上次成功运行至少间隔天数
  state_file: "data/last_run.json"

# AI（DeepSeek，OpenAI 兼容）
ai:
  api_base: "https://api.deepseek.com/v1"
  api_key_env: "DEEPSEEK_API_KEY"
  model: "deepseek-v4-flash"
  prompt_file: "prompts/article.txt"
  min_body_length: 100
  max_body_length: 300
  required_keywords:
    - "三丰云服务器"
    - "免费云服务器"

# 知乎
zhihu:
  write_url: "https://zhuanlan.zhihu.com/write"
  topics:
    - "三丰云服务器"
  auth_state: "auth/zhihu_state.json"
  publish_timeout_sec: 60

# 三丰云（二期启用）
sanfeng:
  enabled: false
  login_url: "https://www.sanfengyun.com/login/"
  form_url: "https://www.sanfengyun.com/control/#/freeServer/532218"
  auth_state: "auth/sanfeng_state.json"
  submit_timeout_sec: 30

# 浏览器
browser:
  headless: false               # 开发阶段 false，稳定后可改 true
  slow_mo: 100                  # 操作间隔(ms)，模拟人工
  viewport:
    width: 1280
    height: 900
```

## 6. 模块详细设计

### 6.1 AI 内容生成（generate_content.py）

**输入**：`prompts/article.txt` + 配置中的话题列表  
**输出**：`{ "title": str, "body": str }`

**提示词建议要点**：

- 要求返回 JSON 格式：`{"title":"...", "body":"..."}`；
- 正文需自然涉及预设话题相关领域；
- 指定字数范围，避免过短或过长；
- 禁止明显营销话术、敏感词（可在 prompt 或后处理中约束）。

**后处理校验**：

- 标题非空，长度建议 10–40 字；
- 正文长度在 `min_body_length` ~ `max_body_length` 之间（当前 100–300 字）；
- 正文必须包含 `required_keywords` 中的全部关键词；
- JSON 解析失败则重试（最多 3 次）。

---

### 6.2 知乎发帖（post_zhihu.py）

#### 6.2.1 登录态检查

1. 使用 `auth/zhihu_state.json` 启动浏览器上下文；
2. 访问 `https://zhuanlan.zhihu.com/write`；
3. 若跳转到登录页或出现登录弹窗 → **终止流程**，日志提示：「知乎登录已过期，请运行 `python scripts/init_zhihu_auth.py` 重新登录」。

> 首次使用前，需单独脚本打开浏览器，人工扫码登录一次，保存 `storageState`。

#### 6.2.2 填写标题

- 定位标题输入框（选择器写入 `selectors.py`，开发时通过 DevTools 确认）；
- 使用 `click()` + `fill()` 或 `keyboard.type()`；
- 填写后短暂等待，确保编辑器状态更新。

#### 6.2.3 填写正文

知乎专栏编辑器多为 **富文本 / contenteditable**，推荐方式（按优先级）：

1. **剪贴板粘贴**：将 body 写入剪贴板，`Ctrl+V` 粘贴（最接近人工操作）；
2. **逐段输入**：`page.keyboard.type(text, delay=20)`（慢但稳）；
3. 避免直接改 innerHTML（易触发 React 状态不同步）。

#### 6.2.4 选择固定话题

对每个配置的话题：

1. 点击「添加话题」或等价按钮；
2. 在搜索框输入话题名；
3. 等待下拉列表出现；
4. 点击匹配项；
5. 关闭弹层（如有）。

**注意**：话题名需与知乎上完全一致；选择器变更时只改 `selectors.py`。

#### 6.2.5 发布与成功判定

1. 点击「发布」按钮；
2. 等待 URL 匹配：`**/zhuanlan.zhihu.com/p/**`（超时 `publish_timeout_sec`）；
3. 可选：检查页面是否出现「审核中」等提示，写入 `meta.json`；
4. `page.screenshot(path=..., full_page=False)`（仅浏览器可视区域）；
5. 返回 `{ "url": page.url(), "screenshot_path": "..." }`。

**失败时不进入三丰云步骤**，避免提交无效 URL。

---

### 6.3 三丰云提交（submit_sanfeng.py）— **二期**

> 一期 `config.yaml` 中 `sanfeng.enabled: false`，主流程在知乎发帖成功后即标记完成。  
> 续期页为 SPA（`#/freeServer/532218`），需补充页面 HTML 后再实现选择器。

#### 6.3.1 登录

1. 加载 `auth/sanfeng_state.json`；
2. 访问 `sanfeng.login_url`；
3. 若已在后台则跳过；若仍在登录页：
   - 浏览器应已自动填充账密；
   - 脚本点击「登录」按钮；
   - 等待跳转至后台首页或目标页。

> 首次使用前，同样需人工登录一次并保存 `storageState`。

#### 6.3.2 表单操作

1. 导航至 `sanfeng.form_url`（续期/提交表单页）；
2. **上传截图**：
   ```python
   page.locator('input[type="file"]').set_input_files(screenshot_path)
   ```
   若为隐藏 input 或拖拽区域，Playwright 仍可对关联的 `input[type=file]` 设文件；
3. 等待上传完成（观察进度条消失、预览图出现或 network 请求结束）；
4. **填写 URL**：在 URL 输入框 `fill(zhihu_url)`；
5. 点击「提交」；
6. 等待成功提示（toast、跳转或成功文案），超时则报错。

#### 6.3.3 开发时需确认的信息

开发前请在浏览器 DevTools 中记录：

- 登录页、表单页的 **准确 URL**；
- 登录按钮、提交按钮的 **选择器**；
- 文件上传控件是标准 `<input type="file">` 还是自定义组件；
- 提交后成功/失败的 **页面反馈**；
- 是否存在 CSRF token 或需额外 hidden 字段（如有，从 DOM 读取后一并提交）。

### 6.4 主流程（main.py）

```python
# 伪代码
def main():
    if not should_run(interval_days=5):
        log.info("距上次成功不足 5 天，跳过")
        return

    output_dir = create_output_dir()
    try:
        content = generate_content()
        save_json(output_dir / "content.json", content)

        result = post_zhihu(content["title"], content["body"])
        update_content_json(result)

        if config["sanfeng"].get("enabled"):
            submit_sanfeng(result["screenshot_path"], result["url"])
        else:
            log.info("三丰云提交未启用（二期），一期流程到此结束")

        mark_success(output_dir)
        log.info("流程成功")
    except Exception as e:
        mark_failure(output_dir, str(e))
        log.error("失败: %s", e)
        raise
```

## 7. 登录态初始化

### 7.1 知乎（一次性 / 过期时）

```bash
python scripts/init_zhihu_auth.py
```

脚本行为：

1. 启动有界面浏览器；
2. 打开 `https://www.zhihu.com/signin` 或 `/write`；
3. 控制台提示：「请手动扫码登录，登录成功后按 Enter」；
4. 保存 `auth/zhihu_state.json`。

### 7.2 三丰云（一次性 / 过期时）

```bash
python scripts/init_sanfeng_auth.py
```

脚本行为：

1. 打开三丰云登录页；
2. 确认浏览器已填充账密（若未填充，人工输入一次并勾选「记住密码」）；
3. 人工点击登录确认成功；
4. 按 Enter 保存 `auth/sanfeng_state.json`。

## 8. 调度方案

### 8.1 脚本内间隔判断（推荐配合任务计划）

`data/last_run.json`：

```json
{
  "last_success_at": "2026-08-21T10:00:00",
  "last_url": "https://zhuanlan.zhihu.com/p/xxxxx"
}
```

每次运行前：若 `now - last_success_at < 5 天`，则退出。

### 8.2 Windows 任务计划程序

- **触发器**：每 5 天一次，或每天检查一次（由脚本内判断间隔）；
- **操作**：`python D:\path\to\sanfeng-auto-renew\main.py`；
- **条件**：仅在计算机网络可用时运行；
- **设置**：失败时记录事件日志。

## 9. 错误处理与重试

| 场景 | 策略 |
|------|------|
| AI 返回非 JSON | 重试最多 3 次 |
| 知乎未登录 | 不重试，通知人工更新 auth |
| 发布超时 | 截图当前页 + 保存 HTML，便于排查 |
| 话题找不到 | 记录可用话题列表截图，终止 |
| 三丰云登录失败 | 不重试，更新 sanfeng auth |
| 文件上传失败 | 等待 5s 重试 1 次 |
| 表单提交无响应 | 超时后报错，保留截图与 URL 供人工补交 |

**原则**：低频场景不做复杂队列；失败即停，保留现场，人工补跑即可。

   ```
   auth/
   output/
   ```
